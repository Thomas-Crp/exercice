# Lancement en local

## Prérequis

* Python 3 installé

## Démarrage

Depuis la racine du projet :

```bash
python3 -m http.server 8000
```

Sous Windows :

```bash
python -m http.server 8000
```

Le serveur est disponible sur :

```text
http://localhost:8000
```

Ouvrir cette URL dans un navigateur pour accéder à l'application.

## Arrêt

Pour arrêter le serveur :

```text
Ctrl+C
```
